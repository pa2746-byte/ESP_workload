# Past graphs from Nsight

Archived results from the February–April 2026 experiments. Original filenames
and the `graph_img/` layout are preserved; file contents were not changed.

- `nsys_*`: Nsight Systems reports, SQLite exports, trace/statistics CSVs,
  flow graphs, and derived interrupt/metric outputs.
- `ncu_*.csv`: associated Nsight Compute metric exports.
- `graph_img/`: rendered graphs from those experiments.
- `synthetic_*`, `tiny_flow_*`, `demo_simple_flow.json`, and
  `n_4_e_4_seed_1_mu_100_sd_50_vseed_24.json`: related synthetic/demo graphs,
  not measured Nsight traces.

The folder name groups the historical experiment results; it does not mean
every file was directly generated by Nsight. Dates refer to Git history.

September 2026 Nsight results remain in `../results/20260923T142233Z/` and
`../results/20260923T215106Z/`. Current source-derived simulator graphs remain
in `../results/logical_transfers/`.

When reusing an archived input, quote paths because this folder name has spaces.
For example, from the repository root:

```bash
python3 flow_graph_networkx.py \
  --input "past graphs from nsight/nsys_dummy_per_iter_flow.json" \
  --name archived_dummy --out-dir results/archive_previews
```

Historical commands in `WORKFLOW_LOG.md` refer to the original root-level
locations. Prefix archived input paths with `past graphs from nsight/`.
